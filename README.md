# Kaampholio Full Stack

Full-stack Kaampholio application with React + TypeScript frontend and Spring Boot backend.

## Project Structure
- frontend/ - React, TypeScript and Vite
- backend/ - Spring Boot and Maven

## Frontend Setup
cd frontend
npm install
npm run dev

## Backend Setup
Requirements: Java, Maven and MySQL.

Configure DB_URL, DB_USERNAME, DB_PASSWORD and APP_PASSWORD as environment variables before starting the backend.

Run the Spring Boot application from the backend directory using Maven.
